Ver cómo conectarlo

Instalación

  1. Descarga o clona el repositorio de Muestrario.
  2. Comprueba que tienes Node.js 22 o posterior.
  3. Para usar los comandos de macOS o Linux, abre la carpeta de Muestrario en la terminal.

Claude Code

claude mcp add --transport stdio --scope user muestrario -- "$(command -v node)" "$PWD/mcp.cjs"

Codex CLI

codex mcp add muestrario -- "$(command -v node)" "$PWD/mcp.cjs"

Cursor, Claude Desktop y otros clientes

Añade la entrada muestrario a mcpServers y sustituye la ruta de ejemplo por la ruta absoluta a mcp.cjs.

Qué puedes consultar

search_library
Busca componentes, webs, apps y patrones originales por texto, tipo, categoría o interacción.
get_entry
Abre una ficha con su descripción, controles, origen y vista previa. Los patrones originales incluyen su código editable.
list_categories
Devuelve las categorías y sus recuentos.
muestrario://catalogue
Índice completo en JSON para clientes que admiten recursos MCP.
